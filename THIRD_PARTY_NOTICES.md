# Third-party software and assets

The MIT license in this repository applies to the study authors' code. It does not relicense external software, atlases, anatomical templates, fonts, or patient data.

Python dependencies are installed separately and retain their own licenses. These include NumPy, SciPy, pandas, scikit-learn, threadpoolctl, and the optional NiBabel and pytest packages.

Image reconstruction, segmentation and registration require separately obtained software. In particular, FreeSurfer and its reference anatomy are not distributed here; users must obtain FreeSurfer and comply with its licensing requirements. A FreeSurfer license file must never be committed to this repository. Other image-processing tools mentioned in the workflow likewise retain their own terms.

This repository does not redistribute downloaded third-party research implementations, clinical images, anatomical reference surfaces, or manuscript illustration assets. A dependency being open source does not imply that all associated datasets or atlases may be redistributed.
